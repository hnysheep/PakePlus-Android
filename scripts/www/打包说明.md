# 声谷音乐 · PakePlus 打包傻瓜教程

> 本目录内文件已经整理完毕，**代码无需任何修改**，按本说明上传 PakePlus 即可生成 APK。
> 已包含：开屏欢迎页（使用你提供的开屏图）、原有全部播放器功能、耳机/蓝牙耳机线控（播放/暂停/上一曲/下一曲/快进退）、后台播放看门狗、媒体卡片进度同步。

## 一、文件清单（zip 根目录必须直接是下面 4 个文件 + 本说明）

```
打包根目录/
├─ index.html            主程序（含开屏欢迎页 + 原播放器全部功能）
├─ splash.jpg             开屏欢迎图（1080×2340，9:19.5 竖屏全屏）
├─ manifest.json         应用清单（应用名、竖屏、 standalone）
├─ default-cover.svg      无封面时的兜底封面（备用素材）
└─ 打包说明.md            本说明
```

### ⚠️ 打包前最关键的一步（最容易出错）
1. 选中上面 **index.html、splash.jpg、manifest.json、default-cover.svg** 这 4 个文件（本 .md 可不进 zip）。
2. 右键压缩成 zip。
3. **打开 zip 检查：里面直接就是 index.html 等文件，不能再套一层同名文件夹！**
   - ✅ 正确：`zip 内 → index.html / splash.jpg / manifest.json / default-cover.svg`
   - ❌ 错误：`zip 内 → 声谷音乐文件夹/ → index.html ...`（套一层会导致页面白屏）

## 二、PakePlus 打包步骤（一步一步跟着点）

### 第 1 步：进入打包入口
打开 PakePlus（网页版或客户端均可），选择 **「网站 / 本地 ZIP 打包 APK」**。

### 第 2 步：上传源码包
- 打包方式选择 **「上传本地 ZIP 包」**。
- 上传你刚压缩好的 zip 文件。
- 首页地址 / 入口保持默认 `./index.html`（若有网址栏，留空或填 `index.html`）。

### 第 3 步：填写基础信息
| 项目 | 填写内容 |
| --- | --- |
| 应用名称 | `声谷音乐` |
| 包名（Package Name） | `com.shengu.musicplayer` |
| 版本名（Version Name） | `1.2.0` |
| 版本号（Version Code） | `120` |
| 应用描述 | `本地音乐播放器，支持歌词、频谱特效与耳机线控` |

### 第 4 步：高级设置（按下面逐项勾选，关系到黑屏能否继续播）
- ✅ **后台音频播放 / 允许音频后台运行**
- ✅ **WakeLock 唤醒锁**（屏幕休眠时保持 CPU 运行，防止声音被掐断）
- ✅ **禁止 WebView 休眠 / 页面不冻结**
- ✅ **禁用后台 JS 节流 / 关闭定时器休眠**
- ✅ **前台服务（音频 / 媒体播放）**（有此选项务必勾选）
- ✅ **允许媒体播放无需用户手势**（`mediaPlaybackRequiresUserGesture = false`）
- ✅ **DOM 存储 / 数据库 / LocalStorage 开启**（导入的歌曲列表要靠它保存）
- ❌ 不要勾选：省电自动暂停、后台自动回收、内存优化杀后台、下拉刷新

### 第 5 步：粘贴 Android 权限（自定义 AndroidManifest 框）
找到 **「自定义 AndroidManifest.xml / 附加权限」** 输入框，完整粘贴下面内容：

```xml
<uses-permission android:name="android.permission.WAKE_LOCK" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK" />
<uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
<uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" android:maxSdkVersion="32" />
<uses-permission android:name="android.permission.BLUETOOTH" />
<uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />
<uses-permission android:name="android.permission.INTERNET" />
```

> 说明：`READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE` 用于手动导入本地歌曲；`WAKE_LOCK` + `FOREGROUND_SERVICE_MEDIA_PLAYBACK` 用于黑屏保活；蓝牙权限用于蓝牙耳机按键切歌。

### 第 6 步：应用图标（可选）
- 若 PakePlus 提供图标上传入口，可用开屏图裁剪成正方形（1:1）上传；不上传则使用默认图标，不影响功能。

### 第 7 步：开始打包
其余选项保持默认，不要开导航栏、广告等额外功能。点击 **「开始打包」**，等待生成完成后下载 APK，传到安卓手机安装。

## 三、安装到手机后必做（否则锁屏容易停播）

国产定制系统的省电策略会主动冻结后台应用，**这是系统限制，不是 APP 故障**。安装后按下面放开权限：

1. **电池/耗电设置（最重要）**
   - 系统设置 → 应用 → 找到「声谷音乐」→ 电池 / 耗电管理。
   - 关闭：省电优化、智能省电、后台自动管理、自动休眠。
   - 选择：**无限制 / 允许后台活动 / 允许后台高耗电**。
   - 小米：选「无限制」；OPPO/vivo：选「允许后台高耗电」；鸿蒙：选「后台持续活动」。

2. **权限管理**
   - 音频 / 媒体文件：允许。
   - 蓝牙：允许（蓝牙耳机切歌需要）。
   - 后台弹出界面：允许。

3. **后台白名单**
   - 手机管家 → 后台清理 / 内存加速 → 把「声谷音乐」加入白名单，锁定后台。
   - 关闭超级省电 / 极限省电模式。

### 自测顺序
1. 打开 APP，看完 3 秒开屏页进入播放器（点屏幕可跳过）。
2. 导入一两首本地歌曲并播放。
3. 锁屏黑屏，等待 10 秒以上，确认音乐继续播放。
4. 用有线耳机 / 蓝牙耳机按键测试：播放、暂停、上一曲、下一曲。
5. 下拉通知栏，查看是否出现媒体卡片与歌曲信息。

## 三·五、卡片式分享怎么用（本版重点）

1. 播放任意一首歌 → 点播放页右上角【分享】；
2. 面板顶部是可点击试听的小卡片，下方按钮：
   - **生成迷你播放器卡片** → 弹出整张卡片大图（封面/歌名/歌手/播放键/品牌）；
   - **复制歌曲链接地址** → 自动复制当前歌曲在线链接，提示「已复制歌曲地址，快分享给你的好友吧」（本地歌曲无在线地址时复制歌曲信息兜底）。
3. 面板下方五个平台 logo（微信、QQ、抖音、微博、小红书）均分并列，小红书为官方红底白字图标：
   - 点击任一 logo：自动复制歌曲链接并尝试唤起对应 App，提示「链接已复制，分享给好友吧」。
4. 卡片封面：优先歌曲封面，网络推荐歌曲与本地歌曲都会按「歌名 + 歌手」自动去网上适配抓图；实在取不到时，封面自动改用声谷音乐 App Logo（深蓝青绿双环 + 金色音符），不会出现空白或破图。
5. 卡片大图页三个按钮：
   - **保存卡片**：优先系统分享发图片，失败则下载到本机，仍失败提示长按保存；
   - **下载并分享**：弹出五个平台选择框；点选平台后自动复制链接、自动下载卡片图、唤起对应 App，提示「歌曲链接已复制，和图片一起分享给你的好友吧」；
   - **关闭**：退出大图预览；选择框内可点「返回」回到卡片按钮。
6. **长按图片**可直接选「保存图片」或发送给好友（提示文字已不再显示）。
7. 卡片大图页三个按钮（保存卡片／下载并分享／关闭）统一为同一金色胶囊样式、等宽并列。

> 卡片为竖版图片，尺寸 720×1020，适合微信/QQ 聊天窗口整张展示。

## 三·七、本地缓存（本版调整）

- 顶部导航「本地歌曲」改名为「**本地缓存**」。
- 搜索框与「歌曲排序方式」之间是三个方格按钮：**全部歌曲** / **我的缓存** / **本地歌曲**，默认停在**全部歌曲**。
- **全部歌曲**：缓存的网络歌 + 本机导入的歌，全部都在这一个列表里；每行保留原有样式，听过的歌在收藏按钮右侧多一个「听过 N 次」小徽章（完整显示，不截断）。
- **我的缓存**：只显示本 APP 自己缓存的内容（下载的网络歌曲 + 生成的分享卡片图片），导入的本地歌曲不在此列；分「正在缓存（带百分比进度条）」「已缓存音乐」「已缓存图片」三块。
- **本地歌曲**：只显示本机导入的歌曲。
- 三个列表都能用「歌曲排序方式」按钮（按时间 / 字母 / 歌手），进入页面默认按**添加时间倒序**——越后添加的越靠前，再点时间按钮可翻转正序；「我的缓存」页不需要排序，按钮自动隐藏。

## 三·八、分享卡片下载（本版加强）

- 生成卡片时就会自动存进「我的缓存」，所以即使没保存成功，也能在 本地与缓存 → 我的缓存 里点开再保存。
- 点【保存卡片】的保存顺序：原生文件接口（打包环境直写手机文档目录）→ blob 直链下载 → 系统分享面板（Android 可选「保存到相册/文件」）→ dataURL 直链，多重兜底；成功会提示「卡片已保存到手机，也能在『我的缓存』里找到」。
- 复制歌曲链接：原生剪贴板插件 → 浏览器剪贴板 API → execCommand 兜底；分享面板里复制后只弹一条对应提示，不再叠加多余 toast。
- 点【下载并分享】选平台时，也会同步下载卡片（静默）+ 复制歌曲链接 + 唤起 App。

## 三·六、退出逻辑（本版调整）

- 退出弹窗提示：「点击「停止播放」，再连续滑动或返回退出。」
- 按钮为【取消】【停止播放】。
- 点【停止播放】：当前正在播的歌立即停止，播放器播放按钮同步变回「播放」态，**APP 不退出**。
- 想继续听歌：必须点播放器上的播放按钮（点后会取消待退出状态，下次返回仍先弹提示）。
- 想真正退出：停止播放后，再连续滑动或按系统返回键一次即退出。

  - 点击「生成迷你播放器卡片」，现场绘制 720×1020 卡片：封面 + 歌名 + 歌手 + 播放按钮 + 声谷音乐品牌；

## 五、已知限制（Web 壳固有的边界）

1. **长时间锁屏后，部分国产 ROM（小米/OPPO/vivo/鸿蒙）仍可能冻结 WebView**，导致媒体卡片按键失效或声音暂停；按第三部分放开后台权限可大幅缓解，但无法做到原生 APP 的 100% 保活。若需要完全稳定的锁屏播放器与通知栏常驻卡片，后续需用 Capacitor 原生 MediaSession + 前台服务实现。
2. Web 壳无法静默全盘扫描本地音乐，安卓端需在导入弹窗里手动多选音频文件。
3. 部分机型对 FLAC / APE 解码支持有限，以实际播放为准。
4. 分享卡片是**图片**，微信/QQ 里显示为图片卡片，不会被识别成可点播的播放器；要变成平台内可点播链接需要各平台开放接口与公网音频地址。
5. 卡片封面取自歌曲 artwork：网络歌曲封面若所在服务器不允许跨域读取，卡片会自动改用音符占位图（不影响生成与分享）。

## 六、常见问题排查

| 现象 | 排查方向 |
| --- | --- |
| 打包后白屏 | 检查 zip 是否套了文件夹；确认 `index.html` 在 zip 根目录；确认 `splash.jpg` 与 `index.html` 同级 |
| 开屏后一直进不去 | 检查浏览器控制台是否有 JS 报错；本目录 `index.html` 两个 script 块已通过语法校验 |
| 锁屏几秒就停 | 电池设置改为无限制；加入后台白名单；确认已勾选 WAKE_LOCK 与前台音频服务 |
| 耳机按键无反应 | 确认蓝牙权限已允许；部分 WebView 不透传媒体按键，可换原生安卓/Chrome 内核壳测试 |
| 导入的歌曲重启后丢失 | 确认高级设置里 LocalStorage / 数据库 / DOM 存储已开启 |
| 通知栏没有媒体卡片 | 属 ROM 兼容问题，网页 MediaSession 在部分国产系统不画卡片；耳机按键可能仍可用 |
| 分享卡生成后保存不了 | WebView 下载受限，长按卡片大图选「保存图片」最稳；或在系统分享面板里选择微信/QQ 直接发送 |

### 三·九 播放状态与选歌状态严格一致（本轮）

- 迷你播放器和主播放器的图标、唱片转动、歌词轮、列表 ▶ 高亮，全部以真实 `<audio>` 是否出声为准，不再提前显示"假播放"。
- 网络选歌（含切上一首/下一首）：先把上一首停掉，界面立刻回到「未播放」——图标为播放三角、唱片停转、歌词轮停；新歌真正出声后由 play 事件自动点亮。
- 上一首的行高亮与 ▶ 序号同步撤掉，不会残留两首歌同时处于播放态。
- 切歌只做 pause、不重建音源，保留后台/锁屏下的可播放授权，避免新歌加载不出来。

### 三·十 进度条随切歌归零（本轮）

- 迷你播放器与全屏播放器两条进度条共用一套逻辑：切歌瞬间两处填充条都回到 0%，当前时间与总时长都显示 0:00。
- 切歌时短暂锁住进度渲染（最多 4 秒兜底），避免旧音频残留的时长把界面写回上一首的进度；新歌 play / loadedmetadata 后自动解锁并接管。
- 删除歌曲导致停播时，同样复用这套归零逻辑，迷你播放器和全屏播放器保持一致。

### 三·十一 歌曲列表默认排序：越后加入越靠前（本轮）

- 全应用默认按「添加时间」倒序：最新导入 / 最新缓存的歌排在最上面，旧歌依次往后。
- 排序按钮逻辑不变：点「时间」在正序（早→晚）与倒序（晚→早）之间切换，图标箭头同步；从歌名 / 歌手切回时间排序，自动回到默认的「越后加入越靠前」。
- 本地缓存三个分栏（全部歌曲 / 我的缓存 / 本地歌曲）沿用同一套排序，进入时默认最新在前。

### 三·十二 我的缓存列表与图片查看（本轮）

- 「我的缓存」里已缓存的音乐，改用与「全部歌曲」完全一致的行样式：序号、封面、来源标签、歌名、歌手、时长、已缓存标签、收藏、三点菜单，点击即可播放。
- 正在缓存的歌同样是这排行样式，右侧显示 0–100% 的进度胶囊，下载完成后自动落进「已缓存音乐」。
- 缓存的图片点击后只弹出「图片查看」：整张大图 + 文件名、存储位置（本机应用内缓存 · 我的缓存 shengu_cached_cards）、时间与大小，底部只有「关闭」，不再进入保存 / 下载并分享流程。

### 三·十三 缓存图片删除 / 删除路径提示 / 长歌名滚动（本轮）

- 「我的缓存 · 已缓存图片」每行右侧新增红色删除按钮，点击弹确认（含存储位置 shengu_cached_cards），确认后立即从缓存中移除并刷新列表。
- 删除歌曲（三点菜单「歌名文件全部删除」）前新增确认框：显示歌名 + 存储位置。缓存的网络歌写明「本机应用内缓存 · 我的缓存（离线音频）」；本地歌显示实际路径；路径缺失或过长时改为「按歌名《…》定位」。
- 列表里歌名超出宽度时不再只显示省略号，而是自动左右来回滚动（按实际溢出宽度计算位移与时长，短歌名保持原样，不加动画）。

### 三·十四 已缓存歌曲去掉 ✓ 图标 / 删除显示文件位置（本轮）

- 已缓存的网络歌在列表里不再显示下载按钮（原来那个实心 ✓），歌名前不会再空出一段；只有还没缓存的网络歌才保留向下箭头的下载按钮。
- 在列表里删除缓存的歌曲（三点菜单「歌名文件全部删除」）时，确认框会显示歌名与文件位置：缓存的网络歌写明「App 私有缓存目录 / 我的缓存（离线音频文件，数据库 shengu_music_db）」，本地歌显示实际路径，路径拿不到时按歌名定位。
